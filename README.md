# Anvil Releases

This repo holds no source code. It exists only to host public download
links for Anvil desktop builds.

Installers are published here automatically by the release pipeline in
the private `sperrodigital/aos` repo — see that repo's `CLAUDE.md`
("Release & distribution") for how the pipeline works.

Stable download links (always resolve to the newest release):

- macOS: https://github.com/sperrodigital/anvil-releases/releases/download/anvil-v0.7.0/Anvil-0.7.0-macos-universal.dmg
- Windows: https://github.com/sperrodigital/anvil-releases/releases/download/anvil-v0.5.0/Anvil-windows-x64-setup.exe
- Linux (AppImage): https://github.com/sperrodigital/anvil-releases/releases/download/anvil-v0.5.0/Anvil-linux-x86_64.AppImage
- Linux (.deb): https://github.com/sperrodigital/anvil-releases/releases/download/anvil-v0.5.0/Anvil-linux-amd64.deb
- Linux (.rpm): https://github.com/sperrodigital/anvil-releases/releases/download/anvil-v0.5.0/Anvil-linux-x86_64.rpm
